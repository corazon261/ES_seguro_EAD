# Etapa 5 — Verificação de Vulnerabilidades

**Sistema/ambiente testado:** RapidoFood ou ambiente autorizado definido pelo grupo

Esta etapa tem como objetivo utilizar uma ferramenta de teste de segurança
para observar vulnerabilidades, alertas e configurações inseguras.

O grupo deverá testar somente o próprio sistema, um sistema cuja análise tenha
sido expressamente autorizada ou uma aplicação deliberadamente vulnerável
executada para fins educacionais.

# ES Seguro — Etapa 1: Casos de Abuso e Modelagem de Ameaças (STRIDE)

> Sistema escolhido: **Aplicativo de Delivery** (entrega de comida/produtos)
>
> Disciplina: Engenharia de Software Seguro (EAD)

## 📌 Sobre este repositório

Este repositório contém o trabalho da **Etapa 1**, cujo objetivo é analisar a
segurança de um sistema de software **antes da implementação**, identificando
ameaças (via STRIDE) e casos de abuso.

O documento principal está em:

- [`docs/modelagem-de-ameacas.md`](docs/modelagem-de-ameacas.md)
